## Does option (b) alone close every path? (the question put to me)
Step B (`route-store.ts:176`) is the only place `/route` sends index text to an external model, and every index source (fresh `load`, warm in-process hit, stale hit while a refresh runs, persisted `route_index` hit) funnels into the same `indexFor` result and then the same line, so a per-request check there closes them at one point regardless of cache or stamp. Walk of the paths:
- Fresh build, warm TTL hit, stale-while-refresh hit, persisted hit: covered (maker tests for the first, second and fourth; my scratch test for the third).
- Step A: local BM25 over index text, no external call. Not a gate concern.
- Frontier composition: `frontierRoot` keeps a doc only when `d.sessionIds.every(allowed)`, and `allowed` is now the intersection of the old gate and `externalGate`. A topic whose refs include a session not in `index.sessionIds` is dropped too (fail closed, `allowed.has` false). A topic with a mixed [eligible, ineligible] ref list is dropped by `every`. This one is by code reading: my scratch attempt to exhibit a mixed topic in the live job did not rank it into the 40-slot frontier, so there is no green run for it.
- Persisted document: holds WhatsApp node text, but it is internal (Mongo); it is never sent externally except through step B.
- Answer hydration: after step B the final `gate(order...)` and hit hydration still use `sessionVisible`, which is link-blind. That is safe today only because real `sessionVisible` returns false for every `whatsapp-batch` session (knowledge.ts:200). See the reachability note and P1.
- Predicate freshness: `external = createKnowledgeVisibility(db)` is built per request, so its memo cannot outlive a request. I pre-warmed an injected visibility's memo to true, revoked the link, and routed: still excluded (the gate does not use `deps.visibility`).
- Read failure: each eligibility read goes through `settle` at half the remaining budget; timeout, throw or non-`true` means not eligible. Fail closed confirmed (maker's hang test plus my `undefined` and missing-row cases).
