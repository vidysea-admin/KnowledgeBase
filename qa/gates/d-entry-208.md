## D-208 | 2026-10-29 | type: decision | status: ACTIVE
**Title:** One KB database on the MONGODB_URL server is the single source of truth (including the vectorless /route index); OnAir mail lane wired into the Linux driver
**What:** Umesh directed on 2026-10-29 (qa/gates/single-db-2026-10-29.md) that the KB keeps all its data in one database it owns on the MONGODB_URL server, the vectorless RAG data included, as the single source of truth. (1) Inventory every place KB state is persisted outside that database (files under data/ and .cache, Docker volumes, in-memory indexes, other databases) in docs/DATA-STORES.md. (2) The /route vectorless index (topic nodes, BM25 terms, facets) is persisted in a route_index collection of the KB database, rebuilt on index/withdrawal and read at start instead of a cold in-memory build. (3) Operational state the inventory finds on disk (scheduler/autojoin state, registration state, live-proof) moves into KB collections, one unit per store; recordings stay files with metadata in Mongo. (4) A copy tool copies one KB database into another on the same server with dry-run, count/hash verification and the D-204 three-part opt-in, so a new database name can be adopted in one command; the target name is a HUMAN_GATE asked at cutover, and nothing is created on the production server before that answer. (5) The WhatsApp archiver database is not touched (D-206 boundary stands). (6) D-207 gap: the OnAir mail lane is wired into scripts/webinar/run-pipeline-deps.mjs so the Ubuntu driver reads OnAir registration mails. isProtectedWorkDbName is never weakened.
**Why:** Umesh wants one place that holds everything; today /route rebuilds from memory (about 4.5 s cold) and several pieces of state exist only as files on one machine, which breaks on the Ubuntu move. The OnAir default-on unit proved the Linux driver never loads the mail lane (run-pipeline-deps.mjs:57-76).
**Result:** Pending: units data-stores-inventory, route-index-persist, kb-db-copy, onair-default-on fix cycle; DB name gate at cutover.
