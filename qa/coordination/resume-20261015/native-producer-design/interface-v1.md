# native-tab-clock/1 — implementation dispatch packet

Proposed root-owned versioned interface, not contract/types changes. Root ACK required before makers export shared declarations. Selected canonical origin is **first independently decoded sample of actual selected provider audio**, not remote acquisition or recorder-start wall time. All earlier media clocks compose into that origin. Native means measured production chain; synthetic fixtures cannot qualify it.

## Central writer lease and shared declarations

Root alone creates `packages/meeting-bot/src/capture/native-media-types.ts`. Browser plain JS consumes the same wire version through strict runtime validators, not a second issuer. Root owns integration joins in `record-consent/provider-input.ts`, tile registry/calibrator/composition and committed-index hook. Makers return primitives and evidence before those joins are activated.

`NativeCaptureIdentity`: `schema: 'native-tab-clock/1'`, server-issued `tenantId`, `sessionId`, `captureGeneration`, `captureInstanceId`, `samplerInstanceId`, `platform`, plus producer browser build, extension asset hash and clock-instance identifier. Values arrive only from the existing server-owned invocation; wire values are equality checks. Do not include a public native boolean, signature secret or caller-selected issuer.

`ProducerVideoObservation`: `frameId`, safe-integer `sourceTimestampUs` diagnostic or null, safe-integer `timestampUs`, `copyBeforeUs`, `copyAfterUs`, `encodedType`, `encodedByteLength`, and `chunkSha256` computed by receiver over bytes. Frame construction and encode input are the same object lineage; chunk output must join exactly by unique timestamp. IVF timebase is rate=1000000/scale=1; stored frame PTS is `timestampUs-firstVideoTimestampUs`, and header frame count is finalized only on complete close. Reject overflow, non-key first frame and unidentified codec changes.

`ProducerAudioObservation`: `blockId`, `startFrame`, `frameCount`, `sampleRate`, `channels:1`, `format:'s16le'`, `byteLength`, receiver-computed `sha256`. AudioWorklet explicitly clamps/rounds mono PCM into this format before transport. Sample indices must be contiguous; intentional gaps require an explicit measured silence-insertion receipt, otherwise poison the generation. No inferred audio timestamp from message arrival.

`AudioClockPair`: bracketed control-thread `beforePerformanceUs`, `contextTime`, `performanceTime`, `afterPerformanceUs`, AudioContext state and sample rate; retain the actual getOutputTimestamp pair, not an invented currentTime offset. `HostClockPair`: bracketed browser performance and epoch reads plus server request/response monotonic/epoch brackets. Units are encoded explicitly; reject mixed clock instances, epoch jumps and unjustified extrapolation. Uncertainty contains separately measured bracket width, clock-fit residual, quantization, audio-output estimation/latency bound and sampler/source-observation lag. Missing bound stays unknown; never turn a residual into a guaranteed estimation error.

`ClosedNativeSpool`: exact physical IVF/PCM/ledger paths, receiver hashes, byte/frame/sample counts, first video timestamp, first audio sample index, identity, and complete/poisoned state. Issued only by private receiver close/readback; builders accept opaque receiver capability or closure-owned state, not arbitrary JSON. Spool files remain private and immutable after close. Publication requires closed markers plus durable hashes; interrupted captures remain incomplete.

`DecodedTransformReceipt`: private exact input/output hashes, source and destination stream identities, rational timebases, decoded first/last PTS/counts, decoder/FFmpeg identity, codec priming/skip/discard, explicit interval map and numeric uncertainty. Mux map starts with `videoHost(t)=Hvideo(firstVideoTimestampUs+t*1e6)` and `audioHost(n)=Haudio((firstAudioFrame+n)/sampleRate)`. Actual decoded output establishes how mux PTS maps to these inputs; flags/durations do not. Provider-audio first decoded sample sets canonical t=0; compose finalization/extraction maps before calibrator issuance.

## Resource/consent and acceptance requirements

PCM s16le mono at 48kHz is 345.6MB/hour before VP8; reserve against a configured private-spool quota before capture, count both raw spools and final candidates, enforce bounded queue and total bytes, and stop safely on quota/error. Raw spools are not public retained output and do not satisfy a 400MB/hour total-storage claim. Existing lean final-output target stays independently enforced. No silent eviction, loss or native recovery from incomplete spools. Resume only identical generation, persisted sequence and byte-hash acknowledgement; foreign/repeated-different chunks poison. Respect current consent capture lifecycle and private source handling; finalization/privacy authority remains mandatory.

Offline fixtures and real-capture acceptance are specified in `design.md`. No actual browser/test execution is authorized by this packet: use the sole broker for validation grants. First source unit is useful only when all three primitives form a reachable path and root activates the verified joins. Candidate-native receipts remain unavailable until independently decoded binding, real platform uncertainty qualification, sampler identity and selected audio origin are all present. Existing synthetic tests cannot supply those facts.
