## Web note
The page citation target is an in-app router path, not an external URL, and a relative path cannot pass safePublicResourceUrl as-is. safePageCitationHref therefore validates id and page, then runs the path as an absolute URL on the fixed placeholder origin https://citation.invalid through safePublicResourceUrl and requires the href to round-trip unchanged; failure renders inert text. If the orchestrator wanted an external public URL here, none exists in the DTO.
