   then `whatsapp` scope. Tenant comes only from verified auth; client tenant/owner/session
   hints never select another identity. No key/bad key => 401; missing scope => 403 before

2. **Current canonical evidence binding.** Resolve the actual canonical schema-valid candidate
   through existing source-bound identity/content/flags validation. Pending and approved
   candidates permit authorized review of their exact evidence. If rejected audit evidence is
   supported, it uses this same private capability and never grants public trust. All evidence
   matches the candidate's source/session and exact current effective quote, speaker and occurrence
   time. A stale/deleted/edited/orphaned/mismatched source or effective transcript correction
   refuses access honestly; no silent raw fallback or fabricated replacement. Failed reads cannot
   be converted into a successful empty proof.
3. **Minimal exact-spans projection.** Return only declared candidate review context and exact

   authorization does not relax normal Brain/search/citation/Ask quarantine.
4. **Shipped queue-to-evidence flow.** Actual ReviewQueue evidence links target the explicit
   reviewer page/capability rather than the quarantined ordinary session endpoint. Candidate and
   turn path/hash identities are encoded and resolve to the exact visibly identified source span,
   including multiple evidence turns where supported. Missing requested passage is an honest
   error/status, never a misleading highlight. Loading, unavailable, forbidden, failed/stale and
   malformed response states are actionable. Normal citation navigation remains separately gated.
5. **Login-session privacy.** The page uses the actual AuthContext `apiKey` and `sessionVersion`
   identity. Credential change, logout or explicit reused-key login clears every private source
   state immediately. Late previous-session success/error callbacks cannot render source text,
   overwrite current error/loading state or invalidate the replacement session. Route/candidate
   switches also discard obsolete responses. No secret or private payload is written to storage,
   logs or cross-tenant client selectors.
6. **Actual consumer and verification.** Same-cycle manifest/packet pins include changed queue
   link, client, page, API source route/store and relevant existing consumers. Independently verify
   auth/scope/tenant/source/freshness boundaries and real queue-to-page-to-API consumption using
   shipped modules, rather than replacing all three with fixtures. Retain exact-field-set negative
   probes, sibling exclusion, effective correction and credential-response races. Green affected
