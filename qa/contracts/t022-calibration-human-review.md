# Contract — T-022 calibration human review intake

This scoped utility prepares human review and validates approval assertions. A PASS does not close T-022/U0.10, authenticate a reviewer, calibrate a live judge, or authorize production tuning. The existing evaluator-calibration contract's derived-versus-human disclosure and production non-goals remain binding.

1. Preparation creates exactly thirty deterministic neutral `(query, node)` items: fifteen current golden questions, each paired with its expected session and recorded distinct semantic rival, distributed into three batches of ten. Every human score, rationale, reviewer and approval time starts null; no proxy score is presented as a human reference.
2. Displayed query, title and summary equal the current golden query and default production session-node judge inputs. Session/page identity and tenant agree; selected sessions share one tenant. Review-only node IDs may use session IDs when that distinction is explicit. Source paths, byte counts and SHA-256 hashes bind the golden set, semantic selection, session/page inputs, tree builder and judge implementation. Legacy proxy inputs/results remain separate and cannot be described as current human gold.
3. Export requires unchanged packet structure and source bindings, exactly thirty items, and each item's finite numeric score within [0,1], nonempty rationale, reviewer assertion exactly `Umesh`, and valid dated approval timestamp. Pending, invalid, foreign-reviewer or drifted packets refuse before output is written. Reviewer assertions are explicitly unauthenticated; software must not manufacture genuine Umesh approval.
4. Approved references are a separately named output preserving each approved score and its input provenance, consumable by the existing `computeMAE` pair interface. Synthetic approval fixtures are test evidence only. Preparation and export never overwrite existing output files.
5. Focused verification covers the real current packet, neutral batching/input binding, pending/invalid/drift refusal, a synthetic approved fractional-score export and immediate MAE consumption, and the required contracts validator. No provider/DB calls, threshold changes, routing changes, historical-result rewrite, or whole-task completion claims occur in this unit.
