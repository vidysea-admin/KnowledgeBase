# Contract: t049-langfuse-trace-sink (written by checker, 2026-10-11)

Ground truth for the Langfuse `TraceSink` (packages/ai/src/trace-langfuse/). Maker never edits this file.

1. Selected ONLY when TELEMETRY_ENABLED=true AND TELEMETRY_SINK=langfuse AND base URL + both keys present and the URL validates; every other environment behaves exactly as at 2d1e738 (file sink / no-op) and never constructs the Langfuse sink. A misconfigured selection falls back to the file sink WITH a stderr warning that names variable names only.
2. Egress allow-list: ids, type, timestamps, name (jobKind), sessionId (correlationId), tenantId, provider, model, level, error CLASS NAME, token counts, costUsd, char counts, retries. Never prompt, completion, transcript, error message, path, key, header, or any unlisted record property. Strings pass only as short labels (<=64 chars of [A-Za-z0-9._:-], no key-looking prefix, no 24+ alphanumeric run) else omitted.
3. TENANT ID (ruling, for the Approver): the tracer contract carries tenantId verbatim by design (caller metadata). It may leave the process inside a trace record ONLY toward the operator-configured, self-hosted, same-trust Langfuse backend (https, or http to loopback). It must not be sent to a third-party or hosted tracing service. Callers must supply generated ids or slugs, never meeting ids, passcodes or personal names, as tenantId or correlationId (a short label-shaped secret cannot be distinguished from an id).
4. Destination: request URL = validated origin + optional path prefix + /api/public/ingestion. https anywhere; http only for localhost/127.0.0.1/[::1]; no userinfo, query, fragment, `@`. redirect "manual"; any 3xx/opaque redirect is a failed attempt with no further request. Credentials only in the Authorization header.
5. Never hurts the call: record() never throws/awaits/returns a promise; bounded queue (drop newest, counted); request timeout wired to AbortController; retries only for network/timeout/5xx, max 2; flush/close bounded; after close no timer or pending promise; no unhandled rejection.
6. Wire format (path, auth, body, event types, 2xx/207) is ASSUMED, unverified against a real instance.
