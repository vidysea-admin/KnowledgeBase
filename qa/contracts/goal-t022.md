## Evidence and ownership rules

- Maker owns its leased application modules, scripts, tests, review package and manifest/packet; never this contract. Central integration owns shared API/web composition, schema/generated/migrations/dependencies, trackers, decisions and publication.
- Checker reads all new code, complete changed logic and immediate consumer/auth/store boundaries, and derives independent probes. No PASS is issued before necessary actual-scope evidence and final hash checks.
- Existing legacy proxy corpus, model receipts and raw media are preserved. Test-generated approvals are temporary fixtures and never written into the real review corpus.
- CPU-sensitive execution requires the root coordinator's lightweight test lease. No browsers, broad suites, paid calls or mutation runs are authorized by this contract itself. Any mutation check follows AGENTS.md timeout/backup/trap/byte-restore rules.
- Historical `t022-calibration-human-review` PASS remains an intake-only certification. Source implementation can be separately certified after C1–C6/C10 pass; final T-022 closure additionally requires C7–C9 and actual integrated review evidence. No contract or prior verdict is relaxed to match an incomplete implementation.
