## Actual authorities and limits

Existing `RecordConsentReceipt` supplies validated tenant/session, immutable capture generation, meeting identity, consent/privacy windows and optional wall-clock `mediaStartedAt`. Its own definition says that the wall-clock origin is not frame/PTS calibration. `PreparedRecordFinalizerInput` binds privacy-approved public-video/receipt bytes, measured duration and guarded privacy windows. `SealedCaptureProviderInput` binds the dispatched audio, receipt, source and capture generation. The strict index proof/current committed index generation binds selected effective transcript and persisted indexing artifacts.

Those authorities are useful inputs; none independently proves a host epoch for decoded sample zero or a generation-bound tile sampler. A registry validator, typed object, Boolean, signature on unmeasured facts or handcrafted JSON cannot create that missing measurement. Actual measurement must have a reachable producer, instrumented source and independently checkable evidence. If it is absent, the correct production result is fixed unavailable with no suggested names.

## Verdict scopes

**Registry source/fixture slice:** A narrower manifest may request independent acceptance of implemented validation/storage/refusal behavior while native calibration and the real hook are absent. Such a PASS must state exactly what was exercised, prove fixed unavailable at missing-authority boundaries, and leave R1/R3/R4/R10/R14 actual-producer/caller gates open. It is not an actual trusted-calibration or mounted-integration PASS.

**Mounted source integration:** A PASS requires the real production edges and real canonical authority consumers to be reachable and exercised, including the calibrated-producer edge. Scripted/synthetic instrumentation may prove source behavior, but must be named as synthetic; actual calibration/runtime/platform success remains unproven without native measured evidence. A composition stub accepting asserted measurement JSON cannot satisfy this scope.

**Full T-042:** Remains governed by goal-T042 P1–P12. Independently referenced real four-panelist attribution, actual platform selectors/cadence/drift, real human confirmation and persisted downstream transcript/KB proof are still required. Neither registry/source PASS nor mounted fixture integration closes the parent.
